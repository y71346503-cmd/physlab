# Проект «Физлаб» (Physlab): бесплатная виртуальная физическая лаборатория

Источник истины для проекта. Изменение от владельца по сравнению с первой версией ТЗ: **весь интерфейс только на английском** (вместо ru/hy/en). Решения и отступления — в DECISIONS.md, ход работ — в PROGRESS.md.

## Цель
Сайт с интерактивными физическими опытами для школьников 7–11 классов. Ученик меняет параметры, видит результат, снимает измерения как на настоящей лабораторной и решает задания с автопроверкой. Главная аудитория — школы Армении, где часто нет оборудования для опытов.

Ориентир по качеству симуляций — PhET. Отличия:
1. Режим «Лабораторная работа»: таблица измерений → график → подгонка прямой → вывод величины с погрешностью (например, g из зависимости T² от L).
2. Задания с автопроверкой к каждому опыту.
3. Полностью офлайн после первого открытия, быстро работает на слабых телефонах.
4. Интерфейс на английском.

## Жёсткие ограничения
- Никаких платных API, серверов, баз данных, аналитики и аккаунтов. Только статический сайт.
- Хостинг: GitHub Pages, деплой через GitHub Actions.
- PWA: после первого визита без интернета работает весь сайт, включая неоткрытые опыты.
- Прогресс ученика — только в localStorage; без него сайт работает, просто не сохраняет.
- Физика честная: реальные формулы, единицы СИ. Упрощения модели названы в теории.
- Ширина 360px, сенсорные экраны, 60 fps на средних телефонах.
- npm-скрипты кроссплатформенные (разработка на Windows).

## Стек
- Vite + TypeScript (strict) + Preact, без state-менеджеров и UI-китов.
- Canvas 2D, своя физика без движков.
- Фиксированный шаг интегрирования, отвязанный от частоты кадров (аккумулятор, ограничение шагов за кадр); пауза в скрытой вкладке.
- KaTeX и Markdown теории рендерятся на этапе сборки; в рантайме только CSS и шрифты KaTeX (лениво).
- Свой лёгкий модуль графиков на Canvas.
- vite-plugin-pwa: precache всех чанков, шрифтов, CSS; уведомление «доступно обновление».
- Хэш-роутинг (`#/exp/pendulum?L=1.2`).
- Vitest для логики, Playwright для smoke-тестов.
- Поля ввода принимают и запятую, и точку.

## Архитектура
Опыт = папка `src/experiments/<id>/`: `meta.ts` (каталог), `index.ts` (контракт `defineExperiment`), `model.ts` (чистая физика + тесты), `sim.ts` (состояние и отрисовка), `tasks.ts`, `lab.ts`, `theory.en.md`. Регистрация автоматическая (import.meta.glob). Общие части — в `src/shared` и `src/components`. Подробно — CLAUDE.md.

## Опыты
1. Математический маятник: L, m, θ₀, место (Земля, Луна, Марс, Юпитер, «Планета X»), затухание. Графики θ, x, v, энергий. Точный период через эллиптический интеграл. Лабораторная: g из T²(L).
2. Бросок под углом: v₀, α, h₀, сопротивление воздуха (квадратичное), масса и диаметр мяча. Лабораторная: дальность от sin 2α → v₀.
3. Наклонная плоскость: α, m, μ (и «неизвестные поверхности»), векторы сил, покой при tg α ≤ μ, фотоворота. Лабораторная: a/cos α от tg α → μ и g.
4. Электрическая цепь: 4 схемы, ЭДС, внутреннее сопротивление, резисторы, лампа (нелинейная), амперметр и вольтметр с выбором места, общий решатель цепи. Лабораторная: ВАХ резистора, R из наклона.
5. Линзы: собирающая и рассеивающая, F, d, h, экран; три луча, тип изображения, особые случаи. Лабораторная: 1/f от 1/d → F.
6. Закон Архимеда: плотности тела и жидкости, объём, глубина погружения, всплытие, мензурка. Лабораторная: F от V → ρ жидкости и ρ тела.

## Приборы
Шкала и цена деления, округление до деления, погрешность — половина деления; секундомер управляет ученик; режим «реальные приборы» с разбросом в пределах класса точности; линейка и транспортир перетаскиваются и управляются с клавиатуры.

## Страница опыта, задания, главная, дизайн
- Сцена, параметры (слайдер + поле), старт/пауза/шаг/сброс/скорость (для динамических), приборы, живой график, вкладки «Theory / Tasks / Lab work».
- Лабораторная: запись измерений, график, МНК с погрешностями, сравнение с эталоном, экспорт CSV, сохранение в localStorage.
- «Share»: параметры в URL, валидация при открытии.
- 5 заданий на опыт: подбор параметра (проверка по состоянию модели), расчёт с допуском (варианты по seed ученика), выбор. Объяснение с формулой.
- Главная: карточки, фильтры по классу и разделу, прогресс, переключатель темы.
- Стиль лабораторного прибора, один акцентный цвет, моноширинные цифры, светлая и тёмная темы, без эмодзи, доступность.

## Качество
- Тесты физики (аналитика vs численное решение), МНК, задания, разбор чисел, параметры URL, полнота контракта.
- Playwright: страницы без ошибок в консоли, 360px без горизонтальной прокрутки, офлайн.
- `npm run check` = типы + тесты + сборка + бюджет размера (главная ≤ 100 КБ gzip, всё без KaTeX ≤ 250 КБ gzip).

## Готово, когда
Все 6 опытов с заданиями и лабораторными, тесты проходят, офлайн работает, деплой настроен; итоговый отчёт с ручными шагами и ссылкой.
